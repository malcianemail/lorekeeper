Homestead Module — Video Summary

Kingdoms of Malcion  |  Companion document for the Homestead demo video  |  July 2026

Homestead lets players create personal indoor Rooms and outdoor Houses, decorate them with owned inventory items in a visual editor, and save layouts — with admin-controlled item rules, slot limits, and full ownership validation.

What Is Homestead?

Homestead is a personal decoration system for players. Each user can:

  • Create indoor Rooms and outdoor Houses
  • Decorate them with items from their inventory
  • Save layouts (furniture placement, wallpaper, flooring, etc.)
  • Return anytime to edit and update their spaces

It is not a shared world or multiplayer builder — each player owns and manages their own rooms and houses.

What the Video Demonstrates

Part 1 — Introduction

Homestead lets players create personal indoor and outdoor spaces and decorate them with inventory items. Layouts are saved per room or house.

Part 2 — Navigation

  • Homestead in the top navbar → Rooms or Houses
  • Rooms (/homestead/rooms) — indoor spaces
  • Houses (/homestead/houses) — outdoor spaces

Both lists work the same way: create, edit, delete, and open the editor.

Part 3 — Create, Edit & Delete Rooms

Players can:

  • Create a room with a name (3–100 characters)
  • Rename via Edit
  • Delete a room (removes layout and all placements)

Each user only sees and manages their own spaces.

Part 4 — Room Editor (Indoor)

The editor includes:

  • Canvas (center) — where furniture is placed
  • Inventory panel (right) — Furniture and Surfaces tabs
  • Save — stores the layout
  • Exit — returns to the rooms list

Furniture tab: click or drag items onto the canvas; drag to move; layer controls and delete for selected items.

Surfaces tab: click wallpaper/flooring to apply wall or floor styles.

After Save, reloading the editor shows the same layout — data is persisted.

Important: The inventory only lists items the user owns and that admins marked as homestead placeable.

Part 5 — House Editor (Outdoor)

Same editor pattern, tuned for outdoor use:

  • Outdoor-style canvas (sky/grass)
  • Items marked for outdoor or both room types
  • Surfaces for ground cover / paths

Saved outdoor layouts persist the same way as indoor rooms.

Part 6 — Building Over Time

Players can start with an empty room/house, add items, see unsaved changes, Save, and Exit. They can return later and keep building — each space saves independently.

Part 7 — Security & Validation

  • Only the owner can edit their room/house
  • Indoor and outdoor URLs are separate (a room cannot be edited via the houses URL)
  • Save rejects invalid data: wrong item type, out-of-bounds placement, placing more than owned quantity
  • Login required — guests cannot access Homestead

Part 8 — Admin Setup (Content Configuration)

Admins configure which items work in Homestead under Admin → Data → Items (click the crown icon in the navbar):

SettingPurpose
Homestead Placeable ItemItem can appear in the editor
Placement TypeFurniture vs surfaces (floor, decoration, wall, flooring, exterior, etc.)
Room TypeIndoor only, outdoor only, or both
Default Width / HeightSize on the canvas (pixels)

Admins grant items to users via Admin → Grants → Item Grants. Until a player owns homestead items, their editor inventory stays empty.

Part 9 — Closing

Homestead gives each player personal rooms and houses, a visual editor, inventory-driven decoration, and saved layouts — with CRUD, ownership checks, and validation built in.

Frequently Asked Questions

Q: Why is my inventory empty in the editor?
A: You need homestead-configured items in your inventory. Admins grant or award them.

Q: Can I use any item?
A: Only items marked Homestead Placeable with the correct room type and placement type.

Q: Can other players edit my room?
A: No — only you (or staff with admin inventory powers).

Q: What happens if I delete a room?
A: The room, its layout, and all placements are removed permanently.
